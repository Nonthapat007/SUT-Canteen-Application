# UI/UX Design Rules
- Strictly no emojis in the UI (buttons, chips, titles, badges, or dialogs).
- Use vector SVG icons (`Icon.js`) only when necessary and available; if none exists, use clean typography without icons.
- Prioritize food-first thumbnails, clean Thai typography, and clutter-free card layouts.
- Follow `.agents/skills/clean-uxui-design/SKILL.md` for complete design guidelines.
